# bike-rental-redi
## Project Overview:
The goal of this project is to develop a Bike Rental System as a terminal-based application using Python. This system will allow users to rent and return bikes, track which bikes have been rented by whom, and manage the availability of bikes in the rental system. The focus is on simulating a small bike rental service.


## Objective:
 - Work with basic data types and structures such as lists, dictionaries.
 - Apply core Python concepts such as loops, conditionals, functions, and file handling.
 - Develop a user-friendly terminal interface for managing customers, bikes, and rentals.
